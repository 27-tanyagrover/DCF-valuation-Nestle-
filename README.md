# Nestlé India – Financial Analysis and Valuation

## Project Overview
This project focuses on analysing Nestlé India's financial performance and estimating its intrinsic value using financial statement analysis and valuation models in Microsoft Excel.

## Analysis Performed
- **Financial Statement Analysis:** Studied historical profit and loss statements and balance sheets to understand the company's financial performance.
- **Ratio Analysis:** Calculated profitability and other financial ratios to assess the company's financial health.
- **Financial Forecasting:** Projected future revenue, expenses, and cash flows using historical data and growth assumptions.
- **WACC Calculation:** Estimated the Weighted Average Cost of Capital to determine the appropriate discount rate.
- **FCFF Valuation:** Used Free Cash Flow to the Firm to estimate the company's value based on projected cash flows.
- **Dividend Discount Model (DDM):** Applied a two-stage DDM using dividend data, growth assumptions, and the cost of equity.
- **Scenario Analysis:** Compared optimistic, base, and worst-case assumptions to understand how different growth rates could affect the valuation.

## Key Learnings
- Learned how to convert financial statements into meaningful financial ratios and valuation inputs.
- Developed practical understanding of WACC, FCFF, CAPM, cost of equity, and terminal value.
- Learned how to forecast financial performance using historical trends and assumptions.
- Understood the difference between FCFF-based valuation and dividend-based valuation.
- Improved Excel skills by linking worksheets, using formulas, and building an integrated valuation model.
- Learned that intrinsic value depends heavily on assumptions about future growth, discount rates, and cash flows.

## Tools and Data Sources
- **Tool:** Microsoft Excel
- **Data used:** Historical profit and loss statements, balance sheets, earnings per share, dividend data, and beta.
- **Reference for beta:** Yahoo Finance.
- **Methods:** Financial ratio analysis, WACC, FCFF, two-stage DDM, and scenario analysis.

## Conclusion
This project helped me apply theoretical finance concepts to a real company and understand how financial analysis and valuation models can support investment decisions. It also taught me the importance of checking assumptions and comparing valuation results rather than relying on a single estimate.
